# Decisiones abiertas y dependencias externas

Actualizado 18-10-2026. La dirección de producto aceptada por el propietario es una aplicación de escritorio **React/Vite/TypeScript, Tauri v2 y Rust/Tokio**, con xterm.js y sincronización DefectDojo opcional. La base elegida por el propietario es SurrealDB embebida con RocksDB; el adaptador de snapshots ya está escrito, aunque el build local está bloqueado por NASM y faltan validar el toolchain nativo, Tauri y el modelo de grafo. El [ADR 0012](../adr/0012-escritorio-tauri-rust.md) registra la decisión y el bloqueo. El equipo es César, Diego y Jhojan; fecha objetivo 31-10-2026 y referencia de hasta 10 h semanales por persona.

No están autorizados objetivos externos para escaneo ni credenciales de APIs OSINT; nunca se deducen del contenido importado. La demo inicial usa fixtures offline. Toda sincronización con DefectDojo requiere una acción explícita del usuario. Las decisiones se registran en issue/ADR/PR; no declarar una propuesta “implementada” por haberla documentado.
