# Borrador — no enviar todavía

Name: **CHEF — Evidence-backed Attack Surface Correlation**

Repository: https://github.com/CyberStill-GmbH/CHEF

Resumen propuesto: Correlacionar observaciones autorizadas de red y HTTP con procedencia verificable y exportaciones reproducibles dentro de Burp.

Valor propuesto: Combinar metadatos HTTP seleccionados dentro del alcance con evidencia Nmap local, conservar las observaciones independientes y explicar por qué existe una relación entre un servicio y un endpoint. La extensión debería funcionar offline, sin un servicio auxiliar. Las relaciones de exposición son hipótesis, no vulnerabilidades confirmadas.

Estado actual: core TypeScript offline para Nmap y prototipo Java/Montoya. La correlación autónoma entre fuentes dentro de Burp, las pruebas de compatibilidad y la validación de tareas con usuarios siguen pendientes. No describir el comportamiento propuesto como una función publicada.

Antes de enviar una postulación, reemplazar este borrador por instrucciones verificadas de instalación y uso, versión mínima real de Burp, comandos de compilación y artefactos, capturas, valores de privacidad, límites, inventario de licencias, consentimiento de autores y resultados de la matriz manual. Registrar la comparación con extensiones similares y evidencia de una diferencia útil. Volver a consultar la plantilla y los criterios vigentes del portal.
