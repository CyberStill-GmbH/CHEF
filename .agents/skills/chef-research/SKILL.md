# chef-research

Usar al actualizar una afirmación de producto, tecnología o BApp Store.

Consultar docs/research/sources.json y el documento afectado. Verificar cada afirmación importante en documentación/repositorio oficial; registrar URL, fecha, versión, claim y limitación. Separar hechos de inferencias y resultados medidos. No ejecutar herramientas de reconocimiento contra infraestructura externa para validar documentación. Comparar funciones existentes antes de afirmar originalidad. Actualizar landscape/ADR con el cambio concreto.

Las rutas mencionadas son relativas a la raíz del repositorio CHEF. Ejecutar npm run check para los cambios pertinentes y registrar resultados reales.
