# Evidencia de producto CHEF

Lee `docs/research/recon-correlation-2026-09.md`, `docs/testing/benchmark.md` y el alcance de demo vigente. Define respuestas correctas antes del ensayo; separa datos sintéticos de fuente real autorizada. Compara la misma tarea CHEF/manual con orden contrabalanceado y registra tiempos, pasos, aciertos, falsos enlaces, errores y muestra real. No inventes participantes, resultados o significación estadística. Conserva resultados negativos.

Explica qué tarea se automatiza: importar, deduplicar, encontrar servicio, revisar relación y exportar evidencia. No equipares número de nodos a utilidad. Un enlace es defendible cuando el evaluador puede ver fuente, fecha, locator y regla. Si el ahorro de tiempo aumenta errores o se pierde evidencia, no se cumple la hipótesis. Publica protocolo y datos agregados sin información de clientes.
