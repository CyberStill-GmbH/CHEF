# chef-demo

Usar al trabajar en guion, fixture/capturas o verificación de presentación.

Leer docs/demo/runbook.md y backlog Q03/Q05. Ejecutar fixture positivo y negativo; registrar commit, entorno y duración real. Separar core implementado de UI/BApp prevista. No usar tráfico real ni Internet como dependencia de demo. Guardar respaldo validado, asignar participación a los tres y ensayar recuperación. No marcar tres ensayos completos sin registros.

Las rutas mencionadas son relativas a la raíz del repositorio CHEF. Ejecutar npm run check para los cambios pertinentes y registrar resultados reales.
